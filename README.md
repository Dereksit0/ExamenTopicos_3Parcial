# Piedra, Papel o Tijera

Juego en Python con interfaz Streamlit. El jugador elige piedra, papel o tijera, la computadora elige al azar y el marcador se mantiene durante la sesión.

## Estructura

```text
app.py
game.py
test_game.py
requirements.txt
docs/diagrama.md
```

## Instalación

Requiere Python 3.12 o superior. Desde la raíz del proyecto:

```powershell
pip install -r requirements.txt
```

## Tests

```powershell
pytest -v
```

## Ejecutar la app

```powershell
streamlit run app.py
```
